# 🛒 ShopSphere 

ShopSphere is a modern **React-based E-commerce Cart Application** that allows users to browse products, add items to cart, and manage shopping selections dynamically.

---

## 🚀 Live Demo

🔗 https://shopsphere-b5tz.vercel.app/

---

## 📌 Features

* 🛍️ Product listing interface
* ➕ Add to Cart functionality
* ❌ Remove from Cart
* 🧮 Dynamic cart item counter
* ⚡ State management using Redux Toolkit
* 📱 Responsive UI using Tailwind CSS
* 🔄 Client-side routing with React Router
* 🌐 Deployed on Vercel

---

## 🧰 Tech Stack

* **Frontend:** React.js
* **State Management:** Redux Toolkit
* **Routing:** React Router DOM
* **Styling:** Tailwind CSS
* **Icons:** React Icons
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

Clone the repository:

```
git clone https://github.com/ankushkumarcity960/shopsphere.git
```

Navigate into project:

```
cd shopsphere
```

Install dependencies:

```
npm install
```

Run locally:

```
npm start
```
